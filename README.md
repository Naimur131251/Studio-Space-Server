
# StudioSpace Server

Backend server for StudioSpace, managing studio data, bookings, and API services.

## Technologies
- Node.js
- Express.js
- MongoDB

## Project Structure
```text
├── data/
│   └── studio-data.json
├── .gitignore
├── index.js
├── seed.js
├── package.json
└── vercel.json
```

## Installation

```bash
npm install
node index.js
```
